They download **Expo Go** app\n2. You give them QR code or link\n3. They scan it\n4. App opens on their phone\n5. They register and start using!\n\n---\n\n## API Endpoints (For Reference)\n\n### Auth\n- `POST /api/auth/register` - Create account\n- `POST /api/auth/login` - Login\n\n### Posts\n- `GET /api/posts` - View all posts\n- `POST /api/posts` - Create post\n- `GET /api/posts/:id` - View post with comments\n\n### Comments\n- `POST /api/comments` - Add comment\n\n### Likes\n- `POST /api/likes` - Like post\n- `DELETE /api/likes/:id` - Unlike post\n\n### Users\n- `GET /api/users/:id` - View profile\n- `PUT /api/users/:id` - Update profile\n\n---\n\n## Database Tables\n\n```\nusers\n├── id (primary key)\n├── username (unique)\n├── email (unique)\n├── password (hashed)\n├── bio\n└── avatar_url\n\nposts\n├── id (primary key)\n├── user_id (foreign key)\n├── title\n├── content\n└── created_at\n\ncomments\n├── id (primary key)\n├── post_id (foreign key)\n├── user_id (foreign key)\n├── content\n└── created_at\n\nlikes\n├── id (primary key)\n├── post_id (foreign key)\n├── user_id (foreign key)\n└── created_at\n```\n\n---\n\n## Mobile App Screens\n\n1. **Login** - Sign in to account\n2. **Register** - Create new account\n3. **Home Feed** - View all posts\n4. **Create Post** - Write new post\n5. **Post Detail** - View post + comments\n6. **User Profile** - View user info\n\n---\n\n## Success Indicators\n\n✓ Backend deployed on Render\n✓ Database is connected\n✓ Mobile app shows home feed\n✓ Can create account\n✓ Can post and comment\n✓ Can like posts\n✓ Can view profiles\n\n**When all are checked, you're done!**\n\n---\n\n## Need Help?\n\n1.
